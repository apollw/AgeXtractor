# Resultados de extração

O destino padrão do terminal e da interface é `resultado.json` nesta pasta.

O resultado existente foi movido para cá sem alterar seu conteúdo. É possível escolher outro arquivo na interface ou usar `python main.py --saida CAMINHO`.

Uma nova execução concluída substitui o resultado escolhido. Cancelamentos e falhas anteriores à gravação final preservam o arquivo existente.
