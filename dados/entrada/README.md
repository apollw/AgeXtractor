# Imagens para extração

Para executar `python main.py` com os padrões do projeto, coloque aqui:

- `placar.jpeg`
- `militar.jpeg`
- `economia.jpeg`
- `tecnologia.jpeg`
- `sociedade.jpeg`

Use a mesma partida e a mesma ordem de jogadores nas cinco imagens. A tabela é localizada automaticamente e pode ser ajustada na interface. O Placar também aceita o nome pontuação.jpeg no terminal.

As fotos atuais têm quatro jogadores: use `python main.py --jogadores 4`. Na interface, selecione cada arquivo na categoria correspondente. Consulte [Extração de fotos](../../docs/EXTRACAO_DE_FOTOS.md).
